## 적용 방법

1. 압축을 푼 무수정 원본의 크기·MD5·CRC32 또는 SHA-256이 위 표와 일치하는지 확인합니다.
2. 아래 해당 패치를 원본에 **한 번만** 적용하고 결과를 별도 파일로 저장합니다.
3. 적용 후 결과 크기와 체크섬을 다음 표와 대조합니다.

xdelta3 사용 예시(모든 경로는 큰따옴표로 묶습니다):

```text
xdelta3 -d -s "Front Mission 1st (Japan).nds" "Front Mission 1st (Korean) v0.8.5_WIP013_260926.xdelta" "Front Mission 1st (Korean) v0.8.5_WIP013_260926.nds"
```

이미 한글화된 ROM에 덧씌우지 않습니다. 원본과 기존 저장 파일은 백업하고, 저장 호환성은 아래 기존 안내의 해당 버전 설명을 따릅니다. 버전이 다른 즉시저장 대신 게임 내 이어하기를 사용하세요.

USA용 BPS는 분석 참고용이다. 일본판 원본에 이번 xdelta 하나만 적용하며 USA 패치나 이전 한글패치를 추가로 적용하지 않는다.
